Every option has three spellings: a flag, an environment variable, and a key in the YAML file
named by `--config FILE` (or `HARDCHARGER_CONFIG`). **A flag wins over an environment
variable, which wins over the file**, which wins over the default. Unknown flags and YAML keys
stop the server. The [configuration guide](/guides/configuration/) shows them in use.

<Aside type="note" title="Generated from the server">
This page is built from `hardcharger-server --print-options-json`, the server's own list of its
options. CI regenerates it from a build of Hardcharger's `main` branch and fails when the
committed copy differs, so the reference can't drift from the server.
</Aside>

Besides the options below, the server takes these command-line actions, which run and exit:

| Action | Does |
|---|---|
| `--config FILE` | Read options from a YAML file (`HARDCHARGER_CONFIG`) |
| `--help` | List every option |
| `--version`, `--print-duckdb-version` | Print the server's or DuckDB's version |
| `--print-options-json` | Print every option as JSON (what this page is built from) |
| `--verify-tls URL` | Fetch a URL over HTTPS with the system's CA bundle, then exit 0 or 1 |
| `--verify-audit-log FILE [--verify-audit-log-partial]` | Check an [audit log](/guides/instrumentation-and-audit/#the-audit-log)'s hash chain |
