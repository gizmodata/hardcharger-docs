Each tab connects to a server on `localhost:31337` as the administrator `hardcharger` with
password `change-me` (as in the [quickstart](/get-started/quickstart/)), runs one query with a
bind parameter, and prints the result.

<Aside>
Every example on this site runs in CI against a real `hardcharger-server` built from `main`.
If one doesn't work for you, that is a bug: please
[open an issue](https://github.com/gizmodata/hardcharger-docs/issues).
</Aside>

<Tabs syncKey="lang">
<TabItem label="Python">

```python test
from adbc_driver_hardcharger import dbapi as hardcharger

with hardcharger.connect(uri="hardcharger://localhost?tls=false",
                         username="hardcharger", password="change-me") as conn:
    with conn.cursor() as cur:
        cur.execute(operation="SELECT 42 AS answer, ? AS greeting", parameters=["hello"])
        print(cur.fetch_arrow_table().to_pylist())
```

```text output
[{'answer': 42, 'greeting': 'hello'}]
```

`hardcharger://localhost` means HTTPS on port 31337; `?tls=false` is plain HTTP for your own
machine. [Install the driver](/clients/python/#install).

<TabItem label="Go">

```go test
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/apache/arrow-go/v18/arrow/memory"
	"github.com/gizmodata/hardcharger-adbc/go/v2/hardcharger"
)

func main() {
	ctx := context.Background()
	db, err := hardcharger.NewDriver(memory.DefaultAllocator).NewDatabaseWithContext(ctx, map[string]string{
		"uri":      "hardcharger://localhost?tls=false",
		"username": "hardcharger",
		"password": "change-me",
	})
	if err != nil {
		log.Fatal(err)
	}
	defer db.Close(ctx)
	cnxn, err := db.Open(ctx)
	if err != nil {
		log.Fatal(err)
	}
	defer cnxn.Close(ctx)
	stmt, err := cnxn.NewStatement(ctx)
	if err != nil {
		log.Fatal(err)
	}
	defer stmt.Close(ctx)
	if err := stmt.SetSqlQuery(ctx, "SELECT 42 AS answer, 'hello' AS greeting"); err != nil {
		log.Fatal(err)
	}
	reader, _, err := stmt.ExecuteQuery(ctx)
	if err != nil {
		log.Fatal(err)
	}
	defer reader.Release()
	for reader.Next() {
		batch := reader.RecordBatch()
		fmt.Println(batch.Column(0), batch.Column(1))
	}
	if err := reader.Err(); err != nil {
		log.Fatal(err)
	}
}
```

```text output
[42] ["hello"]
```

`go get github.com/gizmodata/hardcharger-adbc/go/v2`: the [Go driver](/clients/go/).

<TabItem label="Java">

```java test
Properties properties = new Properties();
properties.setProperty("user", "hardcharger");
properties.setProperty("password", "change-me");
properties.setProperty("useEncryption", "false"); // plain HTTP on localhost
try (Connection connection = DriverManager.getConnection("jdbc:hardcharger://localhost", properties);
     PreparedStatement statement = connection.prepareStatement("SELECT 42 AS answer, ? AS greeting")) {
  statement.setString(1, "hello");
  try (ResultSet rows = statement.executeQuery()) {
    rows.next();
    System.out.println(rows.getInt("answer") + " " + rows.getString("greeting"));
  }
}
```

```text output
42 hello
```

`jdbc:hardcharger://host` uses port 31337 and TLS unless `useEncryption=false`. See
[Java (JDBC)](/clients/jdbc/) for the jar and DBeaver.

Install the [Hardcharger JavaScript driver](https://www.npmjs.com/package/@gizmodata/hardcharger)

```bash
npm install @gizmodata/hardcharger apache-arrow
```

```js test
import { connect } from '@gizmodata/hardcharger';

const conn = await connect({
  url: 'hardcharger://localhost?tls=false',
  username: 'hardcharger',
  password: 'change-me',
});
try {
  const table = await conn.query('SELECT 42 AS answer, ?::VARCHAR AS greeting', ['hello']);
  console.log(table.toArray().map((row) => row.toJSON()));
} finally {
  await conn.close();
}
```

```text output
[ { answer: 42, greeting: 'hello' } ]
```

Use Node.js 22.19 or later. The driver handles authentication, sessions and Arrow results.
See [JavaScript](/clients/javascript/) for streaming, ingest, transactions and browser use.

<TabItem label="curl">

```bash test
TOKEN=$(curl -s localhost:31337/warp/v1/auth/token -H 'Content-Type: application/json' \
  -d '{"grant_type": "password", "username": "hardcharger", "password": "change-me"}' | jq -r .access_token)
SESSION=$(curl -s localhost:31337/warp/v1/sessions -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' -d '{}' | jq -r .session_id)
curl -s localhost:31337/warp/v1/sessions/$SESSION/statements -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' -H 'Accept: application/vnd.apache.arrow.stream' \
  -d '{"sql": "SELECT 42 AS answer, ? AS greeting", "parameters": ["hello"]}' -o result.arrows
python3 -c "import pyarrow.ipc as ipc; print(ipc.open_stream('result.arrows').read_all().to_pylist())"
```

```text output
[{'answer': 42, 'greeting': 'hello'}]
```

The response body is an Arrow IPC stream: any Arrow library reads it.
[Plain HTTP](/clients/http/) covers the rest of the protocol.

## What just happened

1. The client exchanged the password for a **bearer token** (`POST /warp/v1/auth/token`).
2. It opened a **session**, the server-side state of one connection (`POST /warp/v1/sessions`).
3. It **submitted the statement** with its bind parameter. The value travelled as a value,
   never spliced into the SQL, and the result streamed back as Arrow in the same response.

The drivers do all of this for you, and more: retries, resumable downloads, cancel and
partitioned reads. [Warp SQL in one page](/concepts/warp-sql/) explains the model.
