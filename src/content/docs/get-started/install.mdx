The quickest way in is the **[install page](https://gizmodata.com/hardcharger/install)**. It
detects your computer and offers the matching download, with its checksum. This page lists
every option, so you can pick the one that fits.

</Aside>

## Desktop app

The [desktop app](/guides/desktop-app/) runs the server from a graphical dashboard, opens the
SQL workspace and manages settings and logs. Close the dashboard and the server keeps running
in the menu bar or system tray.

- **macOS** (Apple silicon, macOS 15 or later): download the `.dmg` from the
  [install page](https://gizmodata.com/hardcharger/install) and drag Hardcharger to
  Applications, or install it with Homebrew:

  ```bash
  brew install --cask gizmodata/tap/hardcharger-desktop
  ```

- **Windows** (x64 or Arm64): download the signed `.msi` for your computer from the
  [install page](https://gizmodata.com/hardcharger/install). It installs the desktop app with
  its own server and CLI.

## One-line installer

On macOS (Apple silicon) and Linux (x86-64 or arm64, glibc 2.28 or newer), the installer puts
`hardcharger-server` and the `hardcharger` client in `~/.hardcharger`:

```bash
curl https://install.hardcharger.gizmodata.com | sh
```

On Windows, in PowerShell:

```powershell
irm https://install.hardcharger.gizmodata.com/install.ps1 | iex
```

The installer keeps every version you install side by side, checks each download against the
release's SHA-256, and switches between versions in seconds. It prints the line that puts
`~/.hardcharger/bin` on your `PATH`; add `--modify-path` to have it do that:

```bash
curl https://install.hardcharger.gizmodata.com | sh -s -- --modify-path
```

To install a given version, list what you have or uninstall, and for every other option, see
**[hardcharger-install](https://github.com/gizmodata/hardcharger-install)**.

## Homebrew

GizmoData's [Homebrew tap](https://github.com/gizmodata/homebrew-tap) has the server and CLI
for macOS 15+ on Apple silicon and Linux on x86-64 or arm64:

```bash
brew install gizmodata/tap/hardcharger
```

`brew upgrade hardcharger` follows each release. Homebrew keeps one version, the latest; the
one-line installer keeps every version you install.

## Docker

Images are multi-architecture (`linux/amd64`, `linux/arm64`), on `ghcr.io/gizmodata/hardcharger`
and `docker.io/gizmodata/hardcharger`:

```bash
docker run --rm -p 31337:31337 -p 31338:31338 \
  -e HARDCHARGER_ADMIN_PASSWORD='change-me' \
  ghcr.io/gizmodata/hardcharger:latest
```

Port 31337 speaks Chargewire; 31338 answers `/health`. See
[Docker and Kubernetes](/guides/docker-and-kubernetes/) for running it in production.

## Python

The `hardcharger` Python package downloads the release for your platform on first use, checks
its SHA-256, caches it and starts the server for you:

```bash
pip install hardcharger
```

See the [Quickstart](/get-started/quickstart/) for starting a server from Python and
[Python (ADBC)](/clients/python/) for connecting to it.

## Release downloads

Every [release](https://github.com/gizmodata/hardcharger/releases/latest) has tarballs for
Linux (x86-64, arm64) and macOS (Apple silicon), zips and MSIs for Windows (x64, Arm64), the
desktop apps, and a `SHA256SUMS` file covering them all. The
[Quickstart](/get-started/quickstart/) shows how to unpack and start each one.
