These docs describe **version 0.3.0** of Hardcharger, as built from its main branch. Every example runs
against a server built from `main`.

## How versions work

- Hardcharger follows [semantic versioning](https://semver.org). Before 1.0, a minor version
  (`0.3` to `0.4`) may change options or behavior; a patch version only fixes things.
- The server, the `hardcharger` CLI and the container image share one version. The drivers
  ([Python](/clients/python/), [Go](/clients/go/), [JDBC](/clients/jdbc/),
  [JavaScript](/clients/javascript/)) are versioned on their own and speak
  [Warp SQL](/concepts/warp-sql/), whose protocol version the server reports at `GET /warp`
  (`protocol_versions`).
- `HARDCHARGER_VERSION()` and `hardcharger-server --version` report the server's version.
- [Upgrading](/guides/upgrading/) covers moving between versions and rolling back.
